# Composition 示例流程图

## 整体流程图

```
┌─────────────────────────────────────────────────────────────────┐
│                         HOST 端（普通环境）                        │
└─────────────────────────────────────────────────────────────────┘

步骤 1: Alice 生成密钥对
┌─────────────────────────────────────────────────────────────┐
│ let (multiply_receipt, n) = multiply(17, 23);              │
│                                                             │
│ ┌──────────────┐                                           │
│ │ Guest:       │ 读取 a=17, b=23                          │
│ │ multiply     │ 计算 product = 17 × 23 = 391              │
│ │              │ 提交 product 到 journal                   │
│ └──────────────┘                                           │
│         │                                                   │
│         ▼                                                   │
│ ┌──────────────────┐                                       │
│ │ multiply_receipt │ 证明："我知道 391 = 17 × 23"          │
│ │ n = 391          │                                       │
│ └──────────────────┘                                       │
└─────────────────────────────────────────────────────────────┘
         │
         │ multiply_receipt 和 n 发送给 Bob
         ▼

步骤 2: Bob 准备加密
┌─────────────────────────────────────────────────────────────┐
│ ExecutorEnv::builder()                                     │
│   .add_assumption(multiply_receipt)  ← 关键：添加 receipt  │
│   .write(&(n, 9, 100))              ← 写入 (n, e, x)       │
│   .build()                                                  │
└─────────────────────────────────────────────────────────────┘
         │
         │ 执行环境传递给 Guest
         ▼

┌─────────────────────────────────────────────────────────────────┐
│                      GUEST 端（zkVM 环境）                        │
└─────────────────────────────────────────────────────────────────┘

步骤 3: Guest 执行计算
┌─────────────────────────────────────────────────────────────┐
│ fn main() {                                                 │
│   // 1. 读取输入                                            │
│   let (n, e, x) = env::read();                             │
│   // n = 391, e = 9, x = 100                                │
│                                                             │
│   // 2. 验证之前的 receipt（关键步骤！）                     │
│   env::verify(MULTIPLY_ID, &serde::to_vec(&n).unwrap())    │
│   // ✓ 验证成功：n 确实有已知的因式分解                       │
│                                                             │
│   // 3. 计算模幂运算                                        │
│   let c = pow_mod(x, e, n);                                │
│   // c = 100^9 mod 391 = ?                                  │
│                                                             │
│   // 4. 提交结果                                            │
│   env::commit(&(n, e, c));                                  │
│ }                                                           │
└─────────────────────────────────────────────────────────────┘
         │
         │ 生成组合 receipt
         ▼

┌─────────────────────────────────────────────────────────────────┐
│                         HOST 端（验证）                           │
└─────────────────────────────────────────────────────────────────┘

步骤 4: 验证最终 receipt
┌─────────────────────────────────────────────────────────────┐
│ receipt.verify(EXPONENTIATE_ID)                            │
│                                                             │
│ 验证内容：                                                  │
│ ✓ n 有已知的因式分解（通过组合验证 multiply receipt）        │
│ ✓ c = x^e mod n 计算正确                                    │
│                                                             │
│ 最终结果：                                                  │
│ 单一 receipt 同时证明了两个计算！                           │
└─────────────────────────────────────────────────────────────┘
```

## 证明组合的密码学原理（简化）

```
传统方式（两个独立证明）：
┌──────────────┐         ┌──────────────┐
│ Receipt₁     │         │ Receipt₂     │
│ 证明：n有因式 │         │ 证明：c计算正确│
│ 分解          │         │              │
└──────────────┘         └──────────────┘
      │                        │
      └────────┬───────────────┘
               │
               ▼
        需要验证两次

Composition（组合证明）：
┌──────────────┐
│ Receipt₁     │
│ 证明：n有因式 │
│ 分解          │
└──────┬───────┘
       │
       │ 在 Receipt₂ 中验证
       ▼
┌──────────────────────────────┐
│ Receipt₂ (组合)              │
│ ✓ 包含 Receipt₁ 的验证       │
│ ✓ 证明：c计算正确             │
│                              │
│ 结果：单一 receipt 证明两个计算│
└──────────────────────────────┘
       │
       ▼
    只需验证一次
```

## 快速幂算法示例（pow_mod）

计算：100^9 mod 391

```
初始化：
  z = 1    (结果)
  x = 100  (底数)
  e = 9    (指数，二进制：1001)

迭代过程：
┌─────┬──────────┬─────────────────────────┬──────────┐
│ e   │ e % 2    │ 操作                    │ z        │
├─────┼──────────┼─────────────────────────┼──────────┤
│ 9   │ 1 (奇数) │ z = (z × x) mod n       │ 100      │
│     │          │ x = (x × x) mod n       │ 209      │
│     │          │ e = e >> 1              │ 4        │
├─────┼──────────┼─────────────────────────┼──────────┤
│ 4   │ 0 (偶数) │ z 不变                  │ 100      │
│     │          │ x = (x × x) mod n       │ ...      │
│     │          │ e = e >> 1              │ 2        │
├─────┼──────────┼─────────────────────────┼──────────┤
│ 2   │ 0 (偶数) │ z 不变                  │ 100      │
│     │          │ x = (x × x) mod n       │ ...      │
│     │          │ e = e >> 1              │ 1        │
├─────┼──────────┼─────────────────────────┼──────────┤
│ 1   │ 1 (奇数) │ z = (z × x) mod n       │ ...      │
│     │          │ x = (x × x) mod n       │ ...      │
│     │          │ e = e >> 1              │ 0        │
├─────┼──────────┼─────────────────────────┼──────────┤
│ 0   │          │ 结束，返回 z             │ 最终结果  │
└─────┴──────────┴─────────────────────────┴──────────┘
```
