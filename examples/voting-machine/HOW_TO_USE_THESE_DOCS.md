## 💡 学习技巧

### 1. 同步阅读多份文档
```
VS Code 分割窗口：
左 → 源代码（init.rs）
右 → 讲解文档（LEARNING_GUIDE_InitializeCommit.md）

对照理解每一行代码
```

### 2. 逐行添加注释
```
复制 init.rs，为每一行添加中文注释：

let state = env::read();
// 从 Host 读取 VotingMachineState 结构体
// & 表示借用，* 表示解引用
// unwrap() 从 Result 中取值或 panic
```

### 3. 修改并验证
```bash
# 修改 init.rs 代码
# 重新编译
cargo build

# 运行测试
RUST_LOG=info cargo test --release -- --nocapture

# 观察输出变化
```

### 4. 使用编译器错误学习
```
Rust 的错误信息非常详细，比文档更具体！
遇到编译错误时：
  1. 仔细阅读编译器的建议
  2. 在 RUST_SYNTAX_CHEATSHEET.md 中查找相关语法
  3. 尝试按建议修改
```

### 5. 制作思维导图
```
以 InitializeVotingMachineCommit 为中心：

InitializeVotingMachineCommit
  ├─ 数据结构
  │  ├─ polls_open: bool
  │  ├─ voter_bitfield: u32
  │  └─ state: Digest
  ├─ 执行步骤
  │  ├─ 读取状态
  │  ├─ 序列化
  │  ├─ 计算哈希
  │  └─ 提交到 Journal
  └─ 核心概念
     ├─ 哈希函数
     ├─ 借用
     └─ 结构体
```
